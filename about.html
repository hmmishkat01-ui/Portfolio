My Story

From curiosity to craft

It started with a simple question: "How do websites actually work?" I was a teenager, curious about the internet, and I opened browser DevTools for the first time. Seeing the code behind a webpage felt like discovering a secret language. I was hooked.

I spent countless nights learning HTML, CSS, and JavaScript — building tiny projects that nobody saw but that taught me everything. Each bug I fixed, each layout I perfected, each animation I created pushed me deeper into this world.

Today, I work with businesses and entrepreneurs to build digital experiences that actually move the needle. I've learned that the best websites aren't the most flashy — they're the ones that connect with real people and help real businesses grow.

I'm based in Bangladesh, working remotely with clients across the world. Every project I take on, I treat like it's my own — because your success is my success.
